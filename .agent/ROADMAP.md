# 무한 클래식 피아노 플레이어 (MoodFlow Classic) 로드맵

## 1. 프로젝트 개요
- **목적**: 브라우저 Web Audio API 및 그랜드 피아노 물리 배음 모델을 기반으로, 클래식 명곡의 화성학과 아르페지오를 무한 즉흥 연주하는 순수 피아노 웹앱.
- **4대 핵심 클래식 무드**:
  1. ☕ **잔잔한**: 에릭 사티 감성의 나른하고 우아한 짐노페디 왈츠 (3/4박자)
  2. ⚡ **집중**: 바흐 평균율 클라비어 풍의 정갈하고 지적인 16분 음표 분산화음(Arpeggio)
  3. ✨ **신나는**: 모차르트/쇼팽 왈츠 감성의 밝고 화사한 클래식 론도 변주곡
  4. 🌙 **수면**: 쇼팽 녹턴(야상곡) 풍의 아주 느리고 깊은 성당 잔향의 피아노 자장가

## 2. 공용 아키텍처 및 자산 관리
### [구현 완료된 공용 자산 (Implemented Assets)]
- `GrandPianoHarmonicsEngine`: 4중 배음(Harmonics) 및 미세 디튠 기반 어쿠스틱 피아노 사운드 물리 합성기
- `ConcertHallReverb`: 임펄스 응답(Convolver) 기반 3.0초 콘서트홀 공간 잔향 시뮬레이터
- `ClassicalProgressionScheduler`: 바흐 대위법 아르페지오 및 쇼팽 왈츠 베이스/멜로디 분리 스케줄러
- `PianoKeyVisualizer`: 주파수 대역별 건반 타건 동기화 비주얼라이저
